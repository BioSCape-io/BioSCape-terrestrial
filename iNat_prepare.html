Summary

This script reads the cleaned photo dataset produced by botanist_photo_processing.qmd and prepares batch CSV files for the iNaturalist bulk uploader (workflow/dist/iNat_bulk_uploader.exe; see workflow/dist/readme.txt).

Each output row is one corrected species at one plot. Photos of that species at that plot, including different raw spellings and rarefaction species photos, are collapsed into up to 10 media_name_* columns. Kept rows have photo_type == "species" and match_type of exact, fuzzy, spd_fill, or genus_only. Plot photos (cardinal shots, overviews, rarefaction markers, datasheets), blank names, no_match, and excluded rows are not uploaded. Observations are split into batches of 50.

The batch CSVs are written only after two things are true: newfile is populated by the photo-copy chunk, and both numeric observation-field ids below are set. Until then the notebook still builds the observation table so it can be reviewed. field_id* is the number in https://www.inaturalist.org/observation_fields/<id>. The uploader readme documents only these two field pairs.

iNat field Source
id Sequential integer. The uploader prints this as each row starts. It is not the iNaturalist observation id.
taxon_name Corrected binomial, or the corrected genus alone for genus_only
date_obs Earliest photo date, DD/MM/YYYY
time_zone Africa/Johannesburg
description SiteCode_Plot, SiteCode, Plot, taxon, botanist, and photo notes
tag_list BioSCape
latitude, longitude Mean GPS of the photos in the group
location SiteCode_Plot
pos_acc Maximum gps_position_error, in meters
geoprivacy open
field_id1, field_value1 Numeric id of BioSCape SiteCode_Plot, and the SiteCode_Plot value
field_id2, field_value2 Numeric id of BioSCape Genus_Species_combo, and the uploaded taxon
media_name_1–media_name_10 basename(newfile), at most 10. none when that observation has no photo

After upload, the last section reads data/inat_export.csv. iNatID is the export id: the number in https://www.inaturalist.org/observations/<id>, also usable as https://www.inaturalist.org/observations?id=<id>. It is joined on SiteCode_Plot and the uploaded taxon, ignoring case, and written to data/bioscape_veg_plot_species_v20241104_inat.csv and data/bioscape_veg_quadrat_species_v20241104_inat.csv. The v20241104 files are not modified. The same id is copied onto every quadrat row of that species at that plot. Genus-only observations and binomials that are not in the survey are uploaded, and they do not fill iNatID. If two observations match one species row, the smallest id is kept. If the export is not there yet, that section reports so and stops.

Prerequisites:

  1. Run botanist_photo_processing.qmd to produce data/vegphoto_all_<version>.csv.
  2. On iNaturalist, create two observation fields and paste their numeric ids (the number in https://www.inaturalist.org/observation_fields/<id>) into the parameters below. Name them exactly BioSCape SiteCode_Plot and BioSCape Genus_Species_combo. The uploader stores the number, not the name.
  3. Run the photo-copy chunk in botanist_photo_processing.qmd (eval=F) so newfile is written back onto the vegphoto CSV.
  4. The uploader is a Windows program. Copy one batch CSV and every JPEG it names into a single folder, run the exe there, and copy workflow/dist/log.csv aside after each batch. The log is replaced on the next run.

Collapse to one row per species × plot

Show the code 
# One observation = one corrected taxon at one plot. Raw spellings that
# corrected to the same name collapse together. Grouping is on `Plot`, not
# `SiteCode_Plot`, so photos whose site lookup failed are not merged across plots.
# Grouping is not on `Genus_Species_combo`: that column is blank for every
# genus-only photo, and different genera at one plot must stay separate.

nth_photo <- function(photos_list, n) {
  map_chr(photos_list, ~ if (length(.x) >= n) .x[[n]] else NA_character_)
}

inat_obs <- species_photos |>
  arrange(Plot, taxon_name, datetime) |>
  group_by(Plot, taxon_name) |>
  summarise(
    SiteCode            = first(SiteCode),
    SiteCode_Plot       = first(SiteCode_Plot),
    Genus_Species_combo = first(Genus_Species_combo),
    date_obs            = first(date_obs),
    latitude            = mean(gps_latitude, na.rm = TRUE),
    longitude           = mean(gps_longitude, na.rm = TRUE),
    pos_acc             = max(gps_position_error, na.rm = TRUE),
    botanist            = paste(unique(na.omit(botanist)), collapse = ", "),
    notes               = paste(unique(na.omit(description)), collapse = " | "),
    n_photos            = n(),
    photos              = list(head(na.omit(photo_basename), max_media)),
    .groups = "drop"
  ) |>
  mutate(
    pos_acc = if_else(is.infinite(pos_acc), NA_real_, round(pos_acc, 1)),
    notes   = if_else(notes == "", NA_character_, notes)
  )

n_dup <- inat_obs |>
  count(Plot, taxon_name) |>
  filter(n > 1) |>
  nrow()
if (n_dup > 0) {
  stop(n_dup, " plot × taxon combinations are still duplicated after collapse.")

inat_table <- inat_obs |>
  mutate(
    id           = row_number(),
    time_zone    = inat_timezone,
    tag_list     = inat_tag,
    location     = SiteCode_Plot,
    geoprivacy   = "open",
    # Numeric field ids. Values are the strings written at upload so the
    # later join does not depend on iNat's current taxon name.
    field_id1    = field_id_chr(inat_field_id_siteplot),
    field_value1 = SiteCode_Plot,
    field_id2    = field_id_chr(inat_field_id_taxon),

      "BioSCape Vegetation Plot=", SiteCode_Plot,
      "; SiteCode=", SiteCode,

      "; Notes=", notes

fields_ready <- !is.na(inat_field_id_siteplot) && !is.na(inat_field_id_taxon)

if (!newfile_ready || !fields_ready) {
  missing <- c(
    if (!newfile_ready) "newfile (run the photo-copy chunk in botanist_photo_processing.qmd)",
    if (is.na(inat_field_id_siteplot)) "inat_field_id_siteplot",
    if (is.na(inat_field_id_taxon)) "inat_field_id_taxon"
  )
  message(
    "Batch CSVs were not written. Still needed: ",
    paste(missing, collapse = "; "),
    "."
  )
} else {
  if (!dir.exists(batch_dir)) dir.create(batch_dir, recursive = TRUE)

  # A blank media_name_1 makes the uploader abort the row. "none" is the
  # documented token for an observation that has no photo.
  batch_table <- inat_table |>
    mutate(media_name_1 = if_else(is.na(media_name_1), "none", media_name_1))

  batch_ids <- sort(unique(batch_table$batch))
  walk(batch_ids, function(b) {
    batch_file <- file.path(batch_dir, paste0("batch_", sprintf("%02d", b), ".csv"))
    batch_table |>
      filter(batch == b) |>
      select(all_of(template_cols)) |>
      write_csv(batch_file, na = "")
    cat("Wrote:", batch_file, "\n")
  })

  cat("\nAll batches written to:", batch_dir, "\n")
  cat("Total batches:", length(batch_ids), "\n")
  cat("Total observations:", nrow(batch_table), "\n")
}

Next steps

The bulk uploader is the Windows program workflow/dist/iNat_bulk_uploader.exe.

  1. Create the two observation fields on iNaturalist and set inat_field_id_siteplot and inat_field_id_taxon to the numeric ids from their field URLs.
  2. Run the photo-copy chunk in botanist_photo_processing.qmd, then re-run this notebook so newfile is present and the batch CSVs are written.
  3. Copy the JPEGs named in a batch into one folder. media_name_* is a basename, and the program looks only in the folder you select.
  4. Run the exe, choose batch_01.csv and that folder, and submit. Copy log.csv out of the installation folder before the next batch; the program replaces it on every run.
  5. After every batch has uploaded, export the observations to data/inat_export.csv and re-run the section below.

The program cannot add observations to an iNat project. ABORT in the id column stops a run. config.ini beside the exe still holds another person’s paths; choose the CSV and photo folder in the program rather than editing that file.

Write iNatID back to the species tables

iNatID is the observation id in https://www.inaturalist.org/observations/<id>, which is also the id parameter on an observation search. This section runs only when data/inat_export.csv is present. It writes new files and does not modify the v20241104 species tables.

A binomial observation is attached to every quadrat row of that species at that plot. Genus-only observations and binomials that are not in the survey have no matching row, so they do not fill iNatID. If more than one observation matches the same species row, the smallest id is kept and the extras are reported.

} else {
  inat_export <- read_csv(inat_export_file, show_col_types = FALSE)

  # iNat prefixes observation-field columns as "field:<name>".
  field_column <- function(nm, field_name) {
    candidates <- c(field_name, paste0("field:", field_name))
    hit <- nm[str_to_lower(nm) %in% str_to_lower(candidates)]
    if (length(hit) != 1) {
      stop(
        "Expected one column for observation field '", field_name, "'. ",
        "Found: ", if (length(hit) == 0) "none" else paste(hit, collapse = ", "),
        ". Export columns: ", paste(nm, collapse = ", ")
      )
    }
    hit
  }

  if (!"id" %in% names(inat_export)) {
    stop("inat export has no 'id' column. Columns: ",
         paste(names(inat_export), collapse = ", "))
  }

  site_col  <- field_column(names(inat_export), inat_field_name_siteplot)
  taxon_col <- field_column(names(inat_export), inat_field_name_taxon)

  links <- inat_export |>
    transmute(
      iNatID = as.integer(id),
      SiteCode_Plot = str_squish(.data[[site_col]]),
      taxon_uploaded = str_squish(.data[[taxon_col]]),
      combo_key = str_to_lower(taxon_uploaded)
    ) |>
    filter(!is.na(iNatID), SiteCode_Plot != "", taxon_uploaded != "")

  # Only a binomial that exists on a survey row can receive an iNatID.
  # A genus-only value does not equal any Genus_Species_combo.
  survey_keys <- veg_plot_species |>
    distinct(SiteCode_Plot, Genus_Species_combo) |>
    mutate(combo_key = str_to_lower(str_squish(Genus_Species_combo))) |>
    select(SiteCode_Plot, combo_key)

  matched <- links |>
    inner_join(survey_keys, by = c("SiteCode_Plot", "combo_key"))

  extra <- matched |>
    group_by(SiteCode_Plot, combo_key) |>
    filter(n() > 1) |>
    arrange(iNatID) |>
    mutate(kept = iNatID == min(iNatID)) |>
    ungroup()
  if (nrow(extra) > 0) {
    warning(
      n_distinct(paste(extra$SiteCode_Plot, extra$combo_key)),
      " plot × species keys matched more than one iNat observation. ",
      "The smallest iNatID was kept."
    )
    extra |>
      filter(!kept) |>
      select(SiteCode_Plot, taxon_uploaded, iNatID) |>
      print(n = Inf)
  }

  links_one <- matched |>
    group_by(SiteCode_Plot, combo_key) |>
    summarise(iNatID = min(iNatID), .groups = "drop")

  attach_inat <- function(species_file, out_file) {
    species <- read_csv(species_file, show_col_types = FALSE) |>
      mutate(combo_key = str_to_lower(str_squish(Genus_Species_combo))) |>
      left_join(links_one, by = c("SiteCode_Plot", "combo_key")) |>
      select(-combo_key)
    write_csv(species, out_file)
    cat(
      "Wrote ", out_file, " with ", sum(!is.na(species$iNatID)),
      " iNatID values.\n", sep = ""
    )
    invisible(species)
  }

  attach_inat(plot_species_file, plot_inat_file)
  attach_inat(quad_species_file, quad_inat_file)
}
